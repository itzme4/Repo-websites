An AI assistant that lives in your terminal.

Chat with Groq or Gemini from a fast, keyboard-driven Textual interface. Offline models with Ollama are coming soon.

Get started View source

tui-ai ~/terminal






  
Features

  

    
⚡
Never freezes
Replies load in a background thread, so the UI stays smooth while the AI thinks.

    
☁
Groq & Gemini
Pick a provider and model once; switch any time from a simple config file.

    
✔
Guided onboarding
First run asks for your details and API key, validates every field, then drops you into chat.

    
▣
Live status bar
CPU, RAM, battery, time and date, always visible at the top.

    
🔒
Private by design
Keys stay in a per-user .env with owner-only permissions. Nothing is sent anywhere but your chosen provider.

    
◇
Offline soon
Local models through Ollama are on the roadmap, plus an online-or-offline hybrid mode.

Install from source

  
git clone https://github.com/itzme4/TUI_AI.git
cd TUI_AI
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e .
tui-ai

  
Needs Python 3.12+ and a free Groq or Gemini API key. Run tui-ai --config-dir to see where your settings live.
